# サイト構成（技術リファレンス）

このサイトが **どう組み立てられているか** を詳しく書いた資料です。
「どこを直せば、どこに反映されるか」を知りたいときに読んでください。

概要だけ知りたい場合は `AGENTS.md` の4〜8章で足ります。

---

## 1. 全体像

- **ビルド不要の静的HTML**。フレームワークもnpmも使っていません
- 各ページは1つの完結したHTMLファイル。ヘッダー・フッターは各ファイルに直接書かれています
  （テンプレートエンジンを使っていないので、共通部分を変えるときは全ファイルを一括置換します）
- 共通のデザインだけ `css/site.css` に切り出されています
- 一部のページ（`reviews/`、`サイトマップ/`）はPythonスクリプトで自動生成します

### 2-3. 個別レビュー記事（50本）

`/{施設名}/index.html` の形で、リポジトリのルート直下にフォルダが並んでいます。
フォルダ名は日本語のまま（例：`らかんの湯/`、`大阪サウナdesse/`）。

  - `上野ステーションホステル-オリエンタル2-2`（`上野ステーションホステル-オリエンタル2` と同じ施設）

## 3. 施設データ `FACILITIES` の詳細

### 3-1. 置き場所

`ランキング/index.html` の中の `<script>` タグ内。ファイルの中ほどに、
`var FACILITIES = [ … ];` という **1行に176件が詰まった長大な行** があります。

### 3-2. データ構造

```json
{
  "name": "神戸サウナ",
  "pref": "神戸",
  "price": 3100,
  "min": 15,
  "yen_h": 172,
  "total": 66,
  "cospa": 33.4,
  "taipa": 36.5,
  "slug": "神戸サウナ",
  "closed": false,
  "official": "https://www.kobe-sauna.co.jp/"
}
```

| キー | 型 | 説明 |
|---|---|---|
| `name` | 文字列 | 表示される施設名 |
| `pref` | 文字列 | エリア。都道府県とは限らない（「新橋」「巣鴨」「名古屋」なども） |
| `price` | 数値 | 平日料金（円） |
| `min` | 数値 | 主要都市からの所要時間（分） |
| `yen_h` | 数値 | 1時間あたりの料金（円/h） |
| `total` | 数値 | 総合スコア。「総合」タブの並び順に使う |
| `cospa` | 数値 | コスパスコア。「コスパ」タブの並び順に使う |
| `taipa` | 数値 | タイパスコア。表示のみ（並び替えには未使用） |
| `slug` | 文字列 | 記事フォルダ名。**空文字なら記事リンクなし** |
| `closed` | 真偽値 | `true` で「閉店」バッジを表示（現在3軒） |
| `official` | 文字列 | 公式サイトURL。「公式」ボタンのリンク先 |

### 3-3. 数のまとめ

| 項目 | 件数 |
|---|---|
| `FACILITIES` の総数 | 176 |
| うち `slug` があるもの（＝記事あり） | 47 |
| うち `slug` が空のもの（＝名前だけ掲載） | 129 |
| `closed: true` のもの | 3 |

### 3-4. ランキングページの描画ロジック

`ランキング/index.html` の `<script>` 内で、次のように動いています。

1. `FACILITIES` を `total` または `cospa` の降順に並べ替える
2. 各行のHTMLを組み立てて `#ranking-list` に流し込む
3. `slug` があれば施設名をリンクにする（`articleUrl()` が `/` + `encodeURI(slug)` + `/` を作る）
4. MAPボタン（Googleマップ検索）と公式ボタンを付ける
5. タブをクリックすると `render()` が呼ばれ、並べ替えて描き直す

> **既知の注意点**：`hasArticle` の判定は「`slug` が空でないか」だけを見ています。
> `slug` を書いたのに記事フォルダを作っていないと、リンク切れになります。
> 現在は全47件そろっているので問題ありませんが、追加時は注意してください。

## 5. 自動生成ページ

### 5-1. `scripts/gen_reviews.py` → `reviews/index.html`

```bash
python3 scripts/gen_reviews.py
```

- **入力**：`ランキング/index.html` の `FACILITIES` ＋ `data/urls.json`（公開日）
- **出力**：`reviews/index.html`
- **内容**：記事フォルダが実在する47軒を **新着順** に並べ、総合・コスパ・タイパのスコアを表示
- **除外**：重複記事2本（同じ施設名が2回並ぶのを避けるため）
- コラム1本は下部の「COLUMN」欄に別掲

### 5-2. `scripts/gen_sitemapp.py` → `サイトマップ/index.html`

```bash
python3 scripts/gen_sitemapp.py
```

- **入力**：`ランキング/index.html` の `FACILITIES` ＋ `data/urls.json`
- **出力**：`サイトマップ/index.html`
- **内容**：メインページ／施設レビュー全50本（**五十音順**）／サイト情報の3区分で一覧
- レビュー一覧と違い、**重複記事もコラムも全部載せます**（サイトマップは網羅が目的のため）

### 5-3. スクリプトを直すときの注意

両スクリプトとも、Pythonの文字列に **HTMLテンプレートを丸ごと持っています**。
`.format()` を使っているため、テンプレート内の `{` `}` は `{{` `}}` にエスケープが必要です
（JavaScriptの `function(){}` やCSSの `{ }` が該当）。

メニューやフッターを変えたときは、**このテンプレートの中も同じように直してください。**
忘れると、次にスクリプトを実行したときに古い状態に戻ります。

## 6. `data/urls.json`

全ページのメタ情報を持つ配列です。

```json
{
  "id": 581,
  "slug": "神戸-クアハウス",
  "title": "神戸 クアハウス",
  "link": "https://sauna-cospa.com/%e7%a5%9e%e6%88%b8-%e3%82%af%e3%82%a2%e3%83%8f%e3%82%a6%e3%82%b9/",
  "date": "2026-08-23T06:15:06",
  "type": "post"
}
```

| キー | 説明 |
|---|---|
| `id` | WordPress時代の投稿ID。自作ページは `0` |
| `slug` | フォルダ名（`top` だけは例外で `index.html` を指す） |
| `title` | ページタイトル |
| `link` | 公開URL（%エンコード済み） |
| `date` | 公開日時。`reviews/` の並び順に使われる |
| `type` | `"post"`（記事）または `"page"`（固定ページ） |

**用途**：自動生成スクリプトが公開日とタイトルを取るために読みます。
新しい記事を追加したら、ここにも1件足す必要があります。

## 8. CSS（`css/site.css`）

### 8-1. 全体

- 322行。1ファイルにまとまっています
- 先頭の `:root` にデザイン変数（色・フォント）が定義されています（`AGENTS.md` 8章参照）
- 大きく2部構成：
  1. サイト共通（ヘッダー／ナビ／フッター／本文タイポグラフィ）
  2. `.ranking-static` 配下（135行目以降）＝ランキング風リストの部品

### 8-2. よく使うクラス

**ページ骨格**

| クラス | 用途 |
|---|---|
| `.site-header` / `.nav` / `.nav-links` | 上部メニュー |
| `.brand` / `.mark` | ロゴ（金色の角丸に「G」） |
| `.page-main` / `.entry` / `.entry-head` / `.entry-body` | 本文エリア |
| `.site-footer` / `.footer-links` | フッター |

**本文タイポグラフィ**（`.entry-body` の中で自動的に効く）

| 要素 | スタイル |
|---|---|
| `h2` | 金色の下線つき見出し |
| `a` | 金色のリンク |
| `ul` / `li` | 通常のリスト |

**ランキング風リスト**（`.ranking-static` で囲った中で使う）

| クラス | 用途 |
|---|---|
| `.rank-list` | リスト全体。`data-metric="total"` などの属性で色が変わる |
| `.rank-row` | 1行。`has-link` を付けるとホバー効果がつく |
| `.pos` | 左端の順位番号 |
| `.info` > `.nm` / `.pl` | 施設名 / 補足情報（エリア・料金） |
| `.subs` / `.subs-sp` | スコアの小表示（PC用 / スマホ用） |
| `.score` | 右端の大きいスコア |
| `.chip` | MAP・公式などの小さいボタン |
| `.closed-tag` | 「閉店」バッジ |

新しくリスト形式のページを作るときは、これらを再利用すれば統一感が保てます
（`reviews/index.html` がその実例です）。
