## 決定事項と理由

### 運用・体制

- **`AGENTS.md` と `docs/STATE.md` を作成した**
  - 理由：作業ルールを統一し、初心者の利用者にもAIエージェントにも現状が伝わるようにするため。
- **`AGENTS.md` を大幅に拡充し、`docs/` にリファレンスを追加した（2026-09-04）**
  - 理由：内容が薄く、別のAIエージェント（Codex）が作業を引き継げなかったため。
    サイト構成・チェック方法・移行手順を明文化した。

### ページ・機能

- **トップの「レビュー一覧を見る」の飛び先を `/category/review/` から `/reviews/` に変更した**
  - 理由：`/category/review/` はWordPressの一覧ページで、静的サイトには書き出されておらず404だったため。
- **レビュー一覧を `/reviews/`（英字フォルダ）で新設した**
  - 理由：WordPress由来でない自作ページだと区別しやすく、アップロード時の日本語フォルダ名の
    文字化けリスクも避けられるため。
- **レビュー一覧は「新着順」にした**
  - 理由：点数順は既に `/ランキング/` があるため、役割を分けて「新しく書いたものから読む入口」にした。
- **自動生成スクリプト方式にした（`gen_reviews.py` / `gen_sitemapp.py`）**
  - 理由：施設データを2か所に書くと必ずズレるため、`FACILITIES` を唯一の正とするため。
- **重複記事2本（`オアシスサウナ-アスティル-2`、`上野ステーションホステル-オリエンタル2-2`）は
  レビュー一覧に載せていない**
  - 理由：同じ施設名が2回並ぶのを避けるため。ページ自体は残してある。
  - なお **サイトマップには載せている**（網羅が目的のため）。
- **サイトマップページを新設し、全ページのメニューとフッターにリンクを追加した**
  - 理由：利用者からの依頼。`sitemap.xml`（検索エンジン向け）とは別に、人が使える一覧が必要だったため。
- **`sauna-icon-180.png` と `sauna-app.webmanifest` を新規作成した**
  - 理由：`sauna-daigaku.html` がこの2ファイルを読み込んでいたが存在せず404だったため。
    元画像が不明だったので、ブランドカラー（黒×金）とロゴの「G」で新規作成した。
- **`404.html` を新規作成した**
  - 理由：GitHub Pagesは独自ドメイン利用時、ルート直下の `404.html` を自動的に使うため。
    素っ気ないエラー画面ではなくサイトデザインに合わせた案内にした。
- **`reviews` を `data/urls.json` に追加した（2026-09-04）**
  - 理由：整合性チェックで、フォルダはあるのに `urls.json` に未登録だったことが判明したため。

### インフラ

- **WordPressを廃止し、サーバーもGitHub Pagesに一本化する**
  - 理由：利用者の希望（2026-09-04確認）。ConoHaへの手動アップロード運用をやめ、
    GitHubにpushするだけで公開される形にする。サーバー代も不要になる。独自ドメインはそのまま使う。
- **`.nojekyll` を追加した**
  - 理由：GitHub Pagesが標準で動かすJekyllは、アンダースコア始まりのフォルダを無視するなど
    勝手な処理をする。素のHTMLサイトには不要かつ有害になりうるため無効化した。
- **`CNAME` を追加した**
  - 理由：GitHub Pagesで独自ドメイン `sauna-cospa.com` を使うために必要なため。

### 作業ルール

- **`sauna-daigaku.html` は一括処理の対象外とする**
  - 理由：他ページと構造がまったく違う（`css/site.css` を読まない、メニューがJavaScriptのbutton形式、
    約4,900行の単独アプリ的ファイル）。一括置換すると壊れるため。
- **WordPress由来のHTMLタグ閉じ忘れは直さない**
  - 理由：44ファイルに元から存在するが、ブラウザは問題なく表示する。直すと差分が巨大になり、
    本文を壊すリスクの方が大きいため。
