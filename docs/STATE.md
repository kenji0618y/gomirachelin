## このサイトは何か
全国のサウナ施設を独自の10項目で評価し、料金（コスパ）をもとに格付け・紹介する正直ガイドWebサイト「**GOMIRACHELIN（ゴミラシュラン）**」の静的HTMLファイル群です。

## 決定事項と理由

- **`AGENTS.md` と `docs/STATE.md` を新規作成した**
  - **理由**: 作業ルールを統一し、初心者の利用者にもわかりやすくサイトの現状や進捗を管理・共有できるようにするため。
- **トップページの「レビュー一覧を見る」ボタンの飛び先を `/category/review/` から `/reviews/` に変更した**
  - **理由**: `/category/review/` はWordPressの一覧ページで、静的サイト側には書き出されておらず404になっていたため。
- **レビュー一覧ページを `/reviews/`（英字フォルダ）で新規作成した**
  - **理由**: WordPress由来ではない自作ページだと区別しやすく、サーバーへのアップロード時に日本語フォルダ名の文字化けリスクも避けられるため。
- **レビュー一覧は「新着順」にした**
  - **理由**: 点数順は既に `/ランキング/` があるので、役割を分けて「新しく書いたレビューから読める入口」にするため。
- **レビュー一覧を手書きせず `scripts/gen_reviews.py` で自動生成する形にした**
  - **理由**: 施設データを2か所に書くと必ずズレるため、`ランキング/index.html` の `FACILITIES` を唯一の正とするため。
- **同じ施設の重複記事2本（`オアシスサウナ-アスティル-2`、`上野ステーションホステル-オリエンタル2-2`）はレビュー一覧に載せていない**
  - **理由**: 一覧に同じ施設名が2回並ぶのを避けるため。ページ自体は残してあります。

- ランキングの施設データ（`FACILITIES`）が `ランキング/index.html` 内のJavaScriptコードに直接書かれているため、データ更新時の影響範囲に注意が必要な点。
- `10項目別ランキング/index.html` は10個のリストがすべて手書きのため、1軒追加すると10か所を直す必要がある点。
- `sauna-app.webmanifest` と `sauna-icon-180.png` はPR #3でGitHubへ追加済み。ConoHa本番は未変更のため、本番側の有無はバックアップ時に確認する。
- 施設データの「タイパ」が `0.0` のままの施設がいくつかある（例：神戸 クアハウス、SAUNA BUG）。意図的か未入力かは要確認。
- `reviews/index.html` はWordPressから書き出したページではなく、このリポジトリで作ったページです。WordPressから再書き出しをしても自動では作られないので、`python3 scripts/gen_reviews.py` で作り直してください。

## 決定事項と理由

- **`AGENTS.md` と `docs/STATE.md` を新規作成した**
  - **理由**: 作業ルールを統一し、初心者の利用者にもわかりやすくサイトの現状や進捗を管理・共有できるようにするため。
- **トップページの「レビュー一覧を見る」ボタンの飛び先を `/category/review/` から `/reviews/` に変更した**
  - **理由**: `/category/review/` はWordPressの一覧ページで、静的サイト側には書き出されておらず404になっていたため。
- **レビュー一覧ページを `/reviews/`（英字フォルダ）で新規作成した**
  - **理由**: WordPress由来ではない自作ページだと区別しやすく、サーバーへのアップロード時に日本語フォルダ名の文字化けリスクも避けられるため。
- **レビュー一覧は「新着順」にした**
  - **理由**: 点数順は既に `/ランキング/` があるので、役割を分けて「新しく書いたレビューから読める入口」にするため。
- **レビュー一覧を手書きせず `scripts/gen_reviews.py` で自動生成する形にした**
  - **理由**: 施設データを2か所に書くと必ずズレるため、`ランキング/index.html` の `FACILITIES` を唯一の正とするため。
- **同じ施設の重複記事2本（`オアシスサウナ-アスティル-2`、`上野ステーションホステル-オリエンタル2-2`）はレビュー一覧に載せていない**
  - **理由**: 一覧に同じ施設名が2回並ぶのを避けるため。ページ自体は残してあります。
