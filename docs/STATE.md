# サイトの現在の状態（STATE.md）

このファイルは、サイトの現在の状況やできていること、次にやることを記録するためのドキュメントです。

最終更新：2026-09-04（WordPress廃止・GitHub Pages移行の方針が決定）

---

## このサイトは何か
全国のサウナ施設を独自の10項目で評価し、料金（コスパ）をもとに格付け・紹介する正直ガイドWebサイト「**GOMIRACHELIN（ゴミラシュラン）**」の静的HTMLファイル群です。
WordPress（`https://sauna-cospa.com`）から書き出したもので、ConoHaサーバーに直接アップロードして公開するための構成になっています。

## できていること（ページ・機能）

### ページ
- **トップページ (`index.html`)**：キャッチコピー、サイトのコンセプト説明（WHY）、10項目の評価基準、総合トップ3サウナの表示。
- **ランキングページ (`ランキング/index.html`)**：全国176施設のコスパランキング（総合／コスパの切替つき）。記事があるものは施設名から個別レビューへ飛べます。
- **レビュー一覧ページ (`reviews/index.html`)**：記事のあるサウナ47軒を新着順に並べた一覧。**新設（2026-09-04）**。
- **サイトマップページ (`サイトマップ/index.html`)**：全ページ（メインページ・施設レビュー全50件・サイト情報）を一覧できるページ。**新設（2026-09-04）**。上のメニューとフッターの両方から行けます。

- **サウナ大学 (`sauna-university/index.html`, `sauna-daigaku.html`)**：サウナに関する解説記事・コンテンツ。
- **各種案内ページ**：`お問い合わせ`、`運営者情報`、`プライバシーポリシー`、`免責事項`。
- **各サウナ施設の個別レビューページ**：50ページ（うち47軒がランキング掲載施設、1本がコラム、2本が同じ施設の重複記事）。

### 機能・デザイン
- **共通スタイル (`css/site.css`)**：黒背景と金色を基調とした共通のヘッダー・ナビゲーション・フッターデザイン。

- **追加手順のマニュアル (`docs/新規レビュー記事の追加手順.md`)**：新しいサウナのレビューを1軒追加するときの手順書。

## 気になっている点

- `sauna-daigaku.html` と `sauna-university/index.html` という似た役割のファイルが共存している点（Amazonアフィリエイトタグ保持等の理由で別管理されている）。
- ランキングの施設データ（`FACILITIES`）が `ランキング/index.html` 内のJavaScriptコードに直接書かれているため、データ更新時の影響範囲に注意が必要な点。
- `10項目別ランキング/index.html` は10個のリストがすべて手書きのため、1軒追加すると10か所を直す必要がある点。
- 施設データの「タイパ」が `0.0` のままの施設がいくつかある（例：神戸 クアハウス、SAUNA BUG）。意図的か未入力かは要確認。
- `reviews/index.html` はWordPressから書き出したページではなく、このリポジトリで作ったページです。WordPressから再書き出しをしても自動では作られないので、`python3 scripts/gen_reviews.py` で作り直してください。

## 決定事項と理由

- **`AGENTS.md` と `docs/STATE.md` を新規作成した**
  - **理由**: 作業ルールを統一し、初心者の利用者にもわかりやすくサイトの現状や進捗を管理・共有できるようにするため。
- **トップページの「レビュー一覧を見る」ボタンの飛び先を `/category/review/` から `/reviews/` に変更した**
  - **理由**: `/category/review/` はWordPressの一覧ページで、静的サイト側には書き出されておらず404になっていたため。
- **レビュー一覧ページを `/reviews/`（英字フォルダ）で新規作成した**
  - **理由**: WordPress由来ではない自作ページだと区別しやすく、サーバーへのアップロード時に日本語フォルダ名の文字化けリスクも避けられるため。
- **レビュー一覧は「新着順」にした**
  - **理由**: 点数順は既に `/ランキング/` があるので、役割を分けて「新しく書いたレビューから読める入口」にするため。
- **レビュー一覧を手書きせず `scripts/gen_reviews.py` で自動生成する形にした**
  - **理由**: 施設データを2か所に書くと必ずズレるため、`ランキング/index.html` の `FACILITIES` を唯一の正とするため。
- **同じ施設の重複記事2本（`オアシスサウナ-アスティル-2`、`上野ステーションホステル-オリエンタル2-2`）はレビュー一覧に載せていない**
  - **理由**: 一覧に同じ施設名が2回並ぶのを避けるため。ページ自体は残してあります。
- **`sauna-icon-180.png` と `sauna-app.webmanifest` を新規作成した**
  - **理由**: `sauna-daigaku.html` がこの2ファイルを読み込んでいたが存在せず404になっていたため。元のWordPress側にどんなアイコンがあったか分からなかったので、サイトのブランドカラー（黒×金）とロゴの「G」を使って新しく作成した。もし本番のWordPressに元のアイコン画像があれば、そちらに差し替え可能。
- **サイトマップページ（`サイトマップ/index.html`）を新設し、全ページのメニューとフッターにリンクを追加した**
  - **理由**: 利用者から「サイトマップをメニューに出したい」と依頼されたため。`sitemap.xml`（検索エンジン向け）とは別に、人が見て使える一覧ページとして作成した。`scripts/gen_sitemapp.py` で自動生成する形にし、`reviews/index.html` と同じく手書きでズレないようにした。
- **WordPressを廃止し、サーバーもGitHub Pagesに一本化する方針が決まった**
  - **理由**: 利用者の希望（2026-09-04確認）。タイミングは近いうち（数日〜数週間以内）。ConoHaへの手動アップロード運用をやめ、GitHubにpushするだけでサイトが更新される形にする。独自ドメイン（sauna-cospa.com）はそのまま使う予定。
