# ランキング更新手順

最終更新：2026-09-06（Codex）

## 目的

通常ランキングと10項目別ランキングの数字を別々に直す作業をなくし、1か所のデータから静的HTMLを作る。

## 正本

ランキングデータの正本は `data/rankings.json`。

- `facilities`：施設名、地域、料金、移動時間、総合、コスパ、タイパ、記事URL、閉店状態、公式URL
- `axes`：10項目の名前と説明
- 各施設内の `axes.a1` ～ `axes.a10`：10項目の点数

通常ランキングは175施設。10項目の点数がそろっている施設は48施設。地図は国内施設を対象に重複を統合しているため174施設で、対象範囲が1件異なる。

## 更新方法

1. `data/rankings.json` の対象施設だけを編集する。
2. リポジトリのルートで `python scripts/build_rankings.py` を実行する。
3. `python scripts/build_rankings.py --check` を実行し、`OK` を確認する。
4. `python ../check-site-links.py` を実行し、`MISSING=0` を確認する。
5. 通常ランキングと10項目別ランキングをPC・スマートフォンで確認する。
6. `docs/STATE.md` と `docs/AI引き継ぎ.md` を更新し、データ、生成後HTML、記録を同じコミットに入れる。

## 自動更新されるページ

- `ランキング/index.html` 内の施設データ
- `10項目別ランキング/index.html` の10個の順位一覧

見出し、説明文、デザインは自動生成の対象外なので、通常のHTMLとして編集できる。

## 安全確認

- 生成スクリプトは点数の高い順に並べ、同点は `rankings.json` の掲載順を維持する。
- 記事の `slug` がある施設だけ詳細ページへのリンクを表示する。
- `closed: true` は「閉店」表示を付ける。
- `--check` はHTMLが正本データと一致しない場合に失敗する。
- 初回移行用の `--bootstrap` は `rankings.json` が既に存在する場合、上書きせず停止する。
