このリポジトリの静的HTMLは、**上流にあるシステムから生まれたもの**です。
その上流を説明します。**Codexなど新しく参加するエージェントは、この章を読まないと
「データがどこから来たのか」が分からず混乱します。**

> 出典：2026-09-02のClaude引継ぎ資料。2026-09-04にリポジトリへ収録。
> **コードの現物ではなく「記憶からの再構成」なので、最新と異なる可能性があります。**
> 作業前にGASエディタ／スプレッドシートの実物を確認してください。

### ★スプレッドシート操作の落とし穴★

1. **Drive MCP経由の読み取りは約54行目で切り詰められることがある。**
   実際は200件超あるので、「データの終わり」に見えても `getLastRow()` 等で必ず総行数を確認する。

2. **施設名の表記がスプレッドシートと期待値でズレているケースが多い。**
   GASで施設名のMAPを作る前に、**必ず実際のセル値を読み取って確認すること。**

   実際に失敗した例：
   | スプレッドシート上 | 使おうとしたキー | 結果 |
   |---|---|---|
   | `TOTONOI` | `小倉サウナTOTONOI` | ❌ 不一致で書き込み失敗 |
   | `神戸サウナ` | `神戸サウナ&スパ` | ❌ 不一致で書き込み失敗 |

   対策：正規化関数 `norm()` を必ず使う
   （NFKC正規化 + 小文字化 + `&`→`and` + 記号・空白除去）。
   書き込み後は `Logger.log` で一致件数・未一致件数を必ず出力する。

3. **「都道府県」列（col4）の値が不統一。**
   地名・市区町村名・都道府県名がバラバラに入っている。
   GAS側の `PREF_ALIAS` ルックアップテーブル（80件超）で正規化する。
   **シート内では正規化しない方針。**

4. **海外拠点**（例：ユノモリオンセン＆スパ タイランド）は
   正規化の「失敗」ではなく「除外」として扱う。`checkPrefNormalization()` に実装済み。

## 5. WordPress REST API / ブラウザ自動化の知見

> WordPress廃止後は不要になりますが、移行完了までは有用です。

### 認証

```javascript
// wp-adminページ上で利用可能
headers: { 'X-WP-Nonce': wpApiSettings.nonce }
```

### 投稿の一括操作

```javascript
// ループで全投稿を取得
/wp-json/wp/v2/posts?per_page=100&page=N&status=publish&context=edit
// context=edit が必須（content.raw を取得するため）
// PATCHリクエスト間に300msのディレイを挟む（レート制限回避）
```

### 固定ページは別エンドポイント

`/wp-json/wp/v2/pages`（`/posts` とは**別**）
→ 過去にアフィリエイトリンクの一括置換で**固定ページが漏れた前例あり。**

### カスタマイザーCSSの操作

```javascript
// 1. customize.php?autofocus[section]=custom_css に遷移
// 2. 約2秒待機（wp.customize のロード待ち）
// 3. 読み取り：wp.customize.control('custom_css').setting.get()
// 4. 書き込み：wp.customize.control('custom_css').setting.set(newValue)
// 5. 保存：document.querySelector('#save').click()
```

**★致命的な禁止事項★**
`document.body.innerHTML = ''` をカスタマイザーセッション中に**絶対に実行しないこと。**
保存ボタンが消えて保存不能になります。

### ConoHa WINGのWAF

- WAF（Web Application Firewall）がリクエストをブロックすることがある
- **Code Snippets保存時はWAFを一時的に無効化する必要がある**
- REST API経由の投稿で `SyntaxError: Unexpected token '<'` が返る場合、
  HTMLがJSON代わりに返っている → サーバー側の問題
