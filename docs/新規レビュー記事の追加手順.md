# 新しいサウナのレビュー記事を追加する手順

新しく1軒ぶんのレビューを追加するときに、**どのファイルを・どの順番でさわればいいか**をまとめたメモです。
専門用語はできるだけ使っていません。上から順にやれば1軒追加できます。

> 作業をお願いするときは、このファイルを見せて「この手順で〇〇（施設名）を追加して」と伝えればOKです。

---

## 追加する前に決めておくこと

| 決めること | 例 | どこで使うか |
|---|---|---|
| 施設名 | `神戸サウナ` | 全部 |
| フォルダ名（slug） | `神戸サウナ` | ページのURLになる |
| エリア | `神戸` | 一覧の表示 |
| 平日料金 | `3100`（円） | 一覧の表示・コスパ計算 |
| 主要都市からの所要時間 | `15`（分） | 一覧の表示 |
| 1時間あたり料金 | `172`（円/h） | 一覧の表示 |
| 総合／コスパ／タイパ スコア | `66` / `33.4` / `36.5` | ランキング・一覧の並び順 |
| 10項目それぞれの点数 | ①サウナ 8.0 …⑩ホスピタリティ 7.0 | EVALUATIONページ |
| 公式サイトURL | `https://www.kobe-sauna.co.jp/` | 「公式」ボタン |
| 閉店しているか | 開いていれば `false` | 「閉店」バッジ |

---

## 手順

### 1. 記事ページ本体をつくる

1. サイトのフォルダの一番上に、**施設名のフォルダ**を新しくつくる（例：`神戸サウナ`）。
2. すでにある似た記事（例：`神戸サウナ/index.html`）を**コピー**して、新しいフォルダに `index.html` という名前で入れる。
3. その `index.html` の中の次の場所を、新しい施設の内容に書きかえる。
   - `<title>` … `施設名 | GOMIRACHELIN`
   - `<meta name="description" ...>` … 検索結果に出る説明文
   - `<link rel="canonical" href="...">` … `https://sauna-cospa.com/施設名/` にあたるURL
   - `<h1>` … 施設名
   - 本文（レビュー、10項目の点数、アフィリエイトリンクなど）

> **ポイント**：ヘッダー（上のメニュー）とフッター（下のリンク）は、他のページからコピーしたままで大丈夫です。共通の見た目は `css/site.css` が担当しています。

### 2. ランキングに載せる（`ランキング/index.html`）

ファイルの中ほどにある `var FACILITIES = [ ... ];` という長い行に、次のかたちで**1件足す**。

```json
{"name":"神戸サウナ","pref":"神戸","price":3100,"min":15,"yen_h":172,
 "total":66,"cospa":33.4,"taipa":36.5,"slug":"神戸サウナ",
 "closed":false,"official":"https://www.kobe-sauna.co.jp/"}
```

- `slug` は **手順1でつくったフォルダ名と完全に同じ**にすること。ここがずれるとリンク切れになります。
- まだ記事を書いていない施設は `slug` を空 `""` にしておけば、名前だけ載って、リンクは付きません。
- 並び順は自動で点数順になるので、書き足す場所はどこでも構いません。

### 3. 10項目別ランキングに載せる（`10項目別ランキング/index.html`）

このページは①サウナ〜⑩ホスピタリティの**10個のリストが手書き**で並んでいます。
`id="axis-s1"`（①サウナ）〜 `id="axis-s10"`（⑩ホスピタリティ）の各ブロックに、点数順の正しい位置へ1行ずつ足します。1行の形は次のとおりです。

```html
<div class="rank-row has-link"><div class="pos num">7</div><div class="info"><div class="nm"><a class="name-link" href="/施設名/">施設名 <span class="go-arrow">›</span></a></div><div class="pl">神戸</div></div><div class="score num">8.0<span class="s">/10</span></div></div>
```

足したあとは、そのブロックの**順位の番号（`pos`）を振り直す**のを忘れずに。

> ここは10か所さわる必要があって手間がかかるところです。将来ここも自動化できます（→ `docs/STATE.md` の「気になっている点」）。

### 4. ページの一覧データに追加する（`data/urls.json`）

配列の先頭あたりに1件足します。`date` は公開日です。

```json
{ "id": 999, "slug": "神戸サウナ", "title": "神戸サウナ",
  "link": "https://sauna-cospa.com/%e7%a5%9e%e6%88%b8%e3%82%b5%e3%82%a6%e3%83%8a/",
  "date": "2026-08-23T05:25:30", "type": "post" }
```

- `link` のギザギザした文字列は、日本語URLをコンピュータ用に変換したものです。分からなければ `https://sauna-cospa.com/施設名/` のままでも一覧の表示には影響しません。

### 5. レビュー一覧ページを作り直す（自動）

サイトのフォルダで次の1行を実行するだけです。`reviews/index.html` が最新の内容に作り直されます。

```bash
python3 scripts/gen_reviews.py
```

- 手順2の `FACILITIES` と手順4の `data/urls.json` を読んで、**記事フォルダが実際にあるものだけ**を新着順に並べます。
- 手作業で `reviews/index.html` を編集しないでください（次に実行したとき上書きされます）。

### 6. サイトマップに追加する（`sitemap.xml`）

検索エンジンに新しいページを知らせるファイルです。次の4行を足します。

```xml
  <url>
    <loc>https://sauna-cospa.com/施設名/</loc>
    <lastmod>2026-08-23</lastmod>
  </url>
```

### 7. 確認する

パソコンで確認したいときは、サイトのフォルダで次を実行し、ブラウザで `http://127.0.0.1:8000/` を開きます（止めるときは `Ctrl` + `C`）。

```bash
python3 -m http.server 8000
```

見るところ:
- 新しい記事ページが開くか
- `/ランキング/` に載っていて、施設名を押すと記事に飛ぶか
- `/reviews/` に載っているか
- `/10項目別ランキング/` の各項目に入っているか

### 8. 公開する

ConoHaの公開フォルダに、**変更したファイルだけ**を上書きアップロードします。

- 新しい `施設名/index.html`（フォルダごと）
- `ランキング/index.html`
- `10項目別ランキング/index.html`
- `reviews/index.html`
- `index.html`（トップの上位3件を変えた場合のみ）
- `sitemap.xml`
- `data/urls.json`

## 迷ったときのチェックリスト

- [ ] フォルダ名と `slug` が一字一句同じか（全角・半角、`-` の有無に注意）
- [ ] `FACILITIES` に足した `{ ... }` の前後の `,` は正しいか
- [ ] `10項目別ランキング` の順位番号を振り直したか
- [ ] `python3 scripts/gen_reviews.py` を実行したか
- [ ] `sitemap.xml` に足したか
