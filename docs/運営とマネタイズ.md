## 5. サウナ大学（`sauna-daigaku.html`）

サウナに関する総合学習アプリ。ConoHa上に自己完結型の単一HTMLファイル（約93KB / 約4,900行）
として設置されています。

### 機能

- **9章 × 27レッスン**
- **60問以上のクイズ**（4モード：ランダム10問／模擬試験25問〔合格ライン80%〕／全問チャレンジ／弱点復習）
- **XP・レベルシステム**（6段階：サウナ初心者〜サウナ賢者）
- **9種のバッジ**
- ストリーク／デイリーゴール追跡
- **26語の用語集**（ライブ検索付き）
- **AI先生**（Claude Haiku SSEストリーミング、BYOK方式）
  - ローカルナレッジベースのフォールバック（11個のキーワードマッチQ&A）
- 引用元カード（外部参考文献へのリンク）
- ブログCTAパネル（sauna-cospa.comへの誘導）
- モバイルレスポンシブ（ボトムタブバー）

### BYOK（Bring Your Own Key）方式

ユーザーまたはKenjiさん自身がAnthropic APIキーをlocalStorageに入力する方式。
**公開ファイルにAPIキーを埋め込まないためのセキュリティ設計**です。

> **GitHub Pages移行時の注意**：リポジトリを公開にする場合でも、
> BYOK方式なのでキーは漏れません。この設計は維持してください。

### `sauna-university/index.html` との関係

**別物です。** 両方残っているのは意図的：

| ファイル | 正体 |

## 7. セキュリティ注意事項

### 絶対ルール

- `ANTHROPIC_KEY` / `WP_USER` / `WP_APP_PASS` はGASのスクリプトプロパティにのみ保存
- **チャットに絶対に表示しない**
- **スクリプトプロパティ画面のスクリーンショットを要求しない**（平文でキーが見える）
- 過去に**APIキーがチャット内に表示されて漏洩したインシデント**がある
- APIキーは会話に貼らせず、**GAS管理画面上でKenjiさん本人が直接操作する**形を維持する

### ★このリポジトリを公開にする場合の注意★

GitHub Pagesを無料プランで使うには、**リポジトリを公開（public）にする必要があります**
（→ `docs/GitHub-Pages移行手順.md` の警告参照）。

公開前に必ず確認すること：

- [ ] GASのデプロイURL／デプロイキーが書かれていないか
      （**URLを知っているだけで誰でもWebアプリを実行できるため、実質的な認証情報**）
- [ ] スプレッドシートのファイルIDが書かれていないか
- [ ] APIキー・パスワードの類が一切含まれていないか
- [ ] `git log` の過去のコミットにも含まれていないか
      （**一度コミットしたものは公開後も履歴から読めます**）

**現在のドキュメントは、これらを意図的に記載しない方針で書かれています。**
実際の値はGASエディタ／Google Driveで確認してください。
