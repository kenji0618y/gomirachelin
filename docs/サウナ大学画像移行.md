# サウナ大学画像のGitHub移行

最終更新：2026-09-06 12:45 Codex

## 目的

`sauna-daigaku.html` がConoHaの `wp-content/uploads` から読む35枚を、GitHub内の画像へ移し、ConoHaを終了しても表示できるようにする。

## 準備済み

- 保存先：`assets/images/sauna-university/`
- 対象：`sauna-univ-01.jpg` など、HTMLが実際に参照する35枚
- 合計：8,127,222 bytes
- 画像検証：35枚すべてJPEGとして読み込み成功
- ハッシュ一覧：`assets/images/sauna-university/manifest.csv`
- `sauna-daigaku.html` の参照35件を `/assets/images/sauna-university/` へ置換済み
- 旧ConoHa画像URLの残り：0件

## 未反映

画像とHTML修正版はローカルだけにある。GitHub mainへはまだ反映していない。

GitHubの画像アップロード画面で、Chrome拡張機能のファイルURL権限が無効のため `fileChooser.setFiles` が拒否された。

## 次の1手

Chromeで `chrome://extensions` を開き、ChatGPT browser extensionの「詳細」から「ファイルのURLへのアクセスを許可する」をオンにする。設定後、画像35枚を先にアップロードして存在確認し、その後に `sauna-daigaku.html` を反映する。

## 戻し方

HTMLをGitHubへ反映する前なので、現在のGitHub表示には影響しない。反映後に問題があればHTMLだけを旧URLへ戻せる。ConoHa側は変更していない。
