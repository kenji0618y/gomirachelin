# 作業手順とチェック方法

このサイトを変更したときの **動作確認のやり方** と、**実際にハマった落とし穴** をまとめたメモです。
コピペで使えるコマンドを載せています。

---

## 毎回やる3つのチェック

変更したら、コミットする前に必ずこの3つを実行してください。

### ① リンク切れチェック（最重要）

サイト内の全リンクをたどって、リンク先のファイルが実在するか確認します。
このサイトはフォルダ名が日本語で、`href` に `%エンコード` と日本語そのままの2系統が混在しているため、
**目視ではリンク切れを見つけられません。** 必ずこのスクリプトを回してください。

```bash
cd /path/to/gomirachelin
python3 - <<'EOF'
import re, os, glob, urllib.parse, collections
missing = collections.defaultdict(list)
for f in glob.glob('**/*.html', recursive=True):
    html = open(f, encoding='utf-8', errors='replace').read()
    for href in re.findall(r'(?:href|src)="(/[^"#?]*)"', html):
        p = urllib.parse.unquote(href).lstrip('/') or 'index.html'
        if not any(os.path.exists(c) for c in (p, os.path.join(p, 'index.html'))):
            missing[href].append(f)
for k, v in sorted(missing.items()):
    print(k, "->", len(v), "件", v[:3])
print("リンク切れ:", len(missing), "種類")
EOF
```

**期待する結果：`リンク切れ: 0 種類`**

（`%エンコード` されたURLも `urllib.parse.unquote` で日本語に戻してから存在確認しているので、
両方の書き方を同時にチェックできます）

### ② ローカルサーバーで表示を見る

```bash
cd /path/to/gomirachelin
python3 -m http.server 8000
```

ブラウザで `http://127.0.0.1:8000/` を開きます。止めるときは `Ctrl` + `C`。

日本語URLのページを直接開きたいときは、ブラウザのアドレス欄に
`http://127.0.0.1:8000/ランキング/` と日本語のまま打てば開きます。

## メニューを一括で変える

62ファイルが同じヘッダー／フッターを持っています。1つずつ手で直すのは非現実的なので、
Pythonの一括置換スクリプトを書きます。**`sauna-daigaku.html` を必ず除外してください。**

実際に「サイトマップ」をメニューに追加したときのスクリプト（動作実績あり）：

```bash
cd /path/to/gomirachelin
python3 - <<'EOF'
import re, glob

# sauna-daigaku.html は独自構造なので除外する
targets = [f for f in glob.glob('**/*.html', recursive=True) if f != 'sauna-daigaku.html']
changed_nav, changed_footer = [], []

for f in targets:
    s = open(f, encoding='utf-8').read()
    orig = s

    # ヘッダーのメニュー：「お問い合わせ」の直後に追加
    s2 = re.sub(
        r'(<a href="([^"]*お問い合わせ[^"]*)"[^>]*>お問い合わせ</a>\n)( *</nav>)',
        lambda m: m.group(1) + '        <a href="/サイトマップ/">サイトマップ</a>\n' + m.group(3),
        s, count=1)
    if s2 != s:
        changed_nav.append(f); s = s2

    # フッター：「免責事項」の直後（= </ul> の直前）に追加
    s3 = re.sub(
        r'(<li><a href="([^"]*免責事項[^"]*)">免責事項</a></li>\n)( *</ul>)',
        lambda m: m.group(1) + '          <li><a href="/サイトマップ/">サイトマップ</a></li>\n' + m.group(3),
        s, count=1)
    if s3 != s:
        changed_footer.append(f); s = s3

    if s != orig:
        open(f, 'w', encoding='utf-8').write(s)

print("nav更新:", len(changed_nav), "件")
print("footer更新:", len(changed_footer), "件")
print("nav未更新:", set(targets) - set(changed_nav))   # 空になるのが正常
EOF
```

**やったあとの確認**
1. `git diff <適当な1ファイル>` を見て、意図した2行だけが増えているか確認する
2. リンク切れチェックを実行する
3. **自動生成スクリプトのテンプレート（`scripts/gen_*.py` の中のHTML）も同じように直す**
   ← ここを忘れると、次にスクリプトを実行したときにメニューが元に戻ってしまいます

## ★ハマりどころ（実際に踏んだもの）

### 1. ヘッドレスChromeのスクリーンショットで下半分が切れる

**症状**：`--window-size=180,180` を指定したのに、画像の下半分が真っ黒／真っ白になる。

**原因**：デバイスピクセル比が1でないと、指定サイズと実際の描画領域がズレる。

**対策**：`--force-device-scale-factor=1` と `--run-all-compositor-stages-before-draw` を必ず付ける。
それでも合わないときは、大きめのサイズで撮ってから切り取る。

### 2. Pythonの `%` 書式が、%エンコードURLで壊れる

**症状**：
```python
entry = '<loc>https://example.com/%E3%82%B5%E3%82%A4/</loc><lastmod>%s</lastmod>' % today
# → TypeError: must be real number, not str
```

**原因**：URLの中の `%E3` や `%82` を、Pythonが書式指定子だと勘違いする。

**対策**：`%` 演算子を使わず、文字列連結か `.format()` か f-string を使う。

```python
entry = '<loc>https://example.com/%E3%82%B5%E3%82%A4/</loc><lastmod>' + today + '</lastmod>'
```

同じ理由で、`.format()` を使うテンプレート内に `{` `}` があるときは `{{` `}}` にエスケープが必要です
（`scripts/gen_reviews.py` の中のJavaScriptやCSSがこれに該当）。

### 3. HTMLのタグ閉じ忘れが44ファイルで検出されるが、これは直さない

**症状**：HTMLの構文チェックをかけると、44ファイルで「未閉じタグ」「タグの不一致」が出る。

**原因**：WordPressが出力した本文HTMLに元から含まれているもの（`<p>` の閉じ忘れなど）。

**対策**：**直さない。** ブラウザは問題なく表示します。直そうとすると差分が巨大になり、
本文の内容を壊すリスクの方が大きいです。

自分の編集がタグを壊していないかを確認したいときは、**変更したファイルだけ** を個別にチェックし、
`git diff` で「意図した行だけが増減しているか」を見るのが確実です。

```bash
# 新規に作ったファイルなど、単体のチェックはこれで足りる
python3 -c "
from html.parser import HTMLParser
VOID={'br','img','meta','link','input','hr','source','area','base','col','embed','param','track','wbr'}
class P(HTMLParser):
    def __init__(s): super().__init__(); s.stack=[]; s.err=[]
    def handle_starttag(s,t,a):
        if t not in VOID: s.stack.append(t)
    def handle_endtag(s,t):
        if t in VOID: return
        if s.stack and s.stack[-1]==t: s.stack.pop()
        else: s.err.append(t)
p=P(); p.feed(open('サイトマップ/index.html', encoding='utf-8').read())
print('未閉じ:', p.stack, '不一致:', p.err)
"
```

### 4. 自動生成ページを直したのに、次の実行で元に戻る

**症状**：`reviews/index.html` を手で直したのに、あとで元に戻っている。

**原因**：`scripts/gen_reviews.py` が上書きしている。

**対策**：直すのは **スクリプトの中のテンプレート**。そのあとスクリプトを実行して生成し直す。

### 5. サンドボックス環境から本番サイトに接続できない

**症状**：`curl https://sauna-cospa.com/...` が `CONNECT tunnel failed, response 403` で失敗する。

**原因**：リモート実行環境のプロキシが外部サイトへの接続を制限している。

**対策**：本番サイトの中身を確認したいときは、利用者にブラウザで見てもらうか、
スクリーンショットを送ってもらう。Google Fontsも同様に読めないので、
ヘッドレスChromeのスクリーンショットでは日本語フォントが崩れることがあります
（画像を作るなら、ローカルにあるフォント `/usr/share/fonts/opentype/ipafont-gothic/ipag.ttf` を使う）。

### 6. 画像を作りたいが Pillow が入っていない


## 施設データを触るときの注意

`ランキング/index.html` の `FACILITIES` は **1行に176件すべてが詰まった長大な行** です。
テキストエディタで直接編集するとミスしやすいので、Pythonで読み書きするのが安全です。

```bash
# 読む（構造を確認する）
python3 - <<'EOF'
import re, json
s = open('ランキング/index.html', encoding='utf-8').read()
F = json.loads(re.search(r'var FACILITIES = (\[.*?\]);', s, re.S).group(1))
print("施設数:", len(F))
print("記事ありの施設数:", len([x for x in F if x.get('slug')]))
for x in F[:3]:
    print(x)
EOF
```

```bash
# 書き換える（1件追加する例）
python3 - <<'EOF'
import re, json
path = 'ランキング/index.html'
s = open(path, encoding='utf-8').read()
m = re.search(r'(var FACILITIES = )(\[.*?\])(;)', s, re.S)
F = json.loads(m.group(2))

F.append({
    "name": "新しいサウナ", "pref": "東京", "price": 1500, "min": 20, "yen_h": 150,
    "total": 65, "cospa": 35.0, "taipa": 30.0, "slug": "新しいサウナ",
    "closed": False, "official": "https://example.com/",
})

new = m.group(1) + json.dumps(F, ensure_ascii=False) + m.group(3)
open(path, 'w', encoding='utf-8').write(s[:m.start()] + new + s[m.end():])
print("追加しました。合計", len(F), "件")
EOF
```

**書き換えたあとは必ず**：
1. `python3 scripts/gen_reviews.py` と `python3 scripts/gen_sitemapp.py` を実行
2. リンク切れチェック
3. ローカルサーバーで `/ランキング/` を開いて表示を確認

## データの整合性をまとめて確認する

フォルダ・`data/urls.json`・`sitemap.xml`・`FACILITIES` の4つがズレていないか確認します。

```bash
cd /path/to/gomirachelin
python3 - <<'EOF'
import json, os, re, urllib.parse

urls = json.load(open('data/urls.json', encoding='utf-8'))
slugs = {x['slug'] for x in urls}
dirs = {p for p in os.listdir('.')
        if os.path.isdir(p) and not p.startswith('.')
        and p not in ('css', 'data', 'docs', 'scripts')}

print("urls.jsonにあるがフォルダが無い:", sorted(slugs - dirs - {'top'}))
print("フォルダはあるがurls.jsonに無い:", sorted(dirs - slugs))

sm = open('sitemap.xml', encoding='utf-8').read()
sm_slugs = {urllib.parse.unquote(l).replace('https://sauna-cospa.com/', '').strip('/')
            for l in re.findall(r'<loc>(.*?)</loc>', sm)}
print("sitemap.xmlに無いフォルダ:", sorted(dirs - sm_slugs))

fac = json.loads(re.search(r'var FACILITIES = (\[.*?\]);',
                 open('ランキング/index.html', encoding='utf-8').read(), re.S).group(1))
bad = [x['slug'] for x in fac if x.get('slug')
       and not os.path.exists(os.path.join(x['slug'], 'index.html'))]
print("FACILITIESのslugだが記事が無い:", bad)
EOF
```

**正常なら、`top` 以外はすべて空リストになります。**
（`top` は `index.html` に対応するため、フォルダが存在しないのが正常です）
