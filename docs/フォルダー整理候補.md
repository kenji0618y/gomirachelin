# GitHubフォルダー整理候補

最終更新：2026-09-07（Codex）

## 結論

公開URLを壊さないため、施設ページのフォルダーは今すぐ移動しない。先に不要候補を記録し、内容比較とリダイレクト方針を決めてから小分けに整理する。

## 現在の構成

- 公開ページ：トップ直下の施設フォルダー、`why/`、`ランキング/`、`10項目別ランキング/`、`reviews/`、`sauna-university/`、`map/`、お問い合わせ・運営情報・規約ページ
- 共通素材：`assets/`、`css/`
- データと生成：`data/`、`scripts/`
- 運用記録：`docs/`

施設フォルダーを `facilities/` などへまとめると公開URLが変わり、検索結果・ブックマーク・既存リンクに影響する。この整理は独自ドメイン切替より前に行わない。

## 内容確認が必要な重複候補

| 候補 | 現在のHTMLリンク数 | 対応する既存フォルダー | 状況 |
|---|---:|---|---|
| `オアシスサウナ-アスティル-2/` | 0 | `オアシスサウナ-アスティル/` | 同じタイトルのWordPress投稿が2件。ID 456（2026-08-08）とID 155（2026-06-23） |
| `上野ステーションホステル-オリエンタル2-2/` | 0 | `上野ステーションホステル-オリエンタル2/` | 同じタイトルのWordPress投稿が2件。ID 452（2026-08-08）とID 186（2026-06-23） |

どちらもファイル内容が異なるため、旧URLのフォルダーは削除しない。旧投稿記録は `data/url-history.json` に分け、`data/urls.json` には現在使うURLだけを残した。

## 内容比較の結果

### オアシスサウナ アスティル

- 現在ランキングとレビュー一覧が参照する正式URL候補は、接尾辞なしの `オアシスサウナ-アスティル/`。
- 接尾辞なしのページは本文がほぼなく、広告・注意書き・関連リンクが中心になっている。
- `オアシスサウナ-アスティル-2/` には、総合60点・コスパ21.4を含む評価内訳とレビュー本文がある。ランキング側の点数とも一致する。
- 推奨：公開URLは接尾辞なしを維持し、`-2` 側の完全な本文を接尾辞なしへ移す。移した後も `-2` はすぐ削除せず、リダイレクト方式を決めるまで保存する。

### 上野ステーションホステル オリエンタル2

- 現在ランキングとレビュー一覧が参照する接尾辞なしの `上野ステーションホステル-オリエンタル2/` に、総合64点・コスパ27.5を含む評価内訳とレビュー本文がある。
- `上野ステーションホステル-オリエンタル2-2/` は本文がほぼない。
- 接尾辞なしを正式ページとして維持した。`-2` は削除せず、`noindex`、正式URLcanonical、即時移動、手動リンクを持つ案内ページにした。

比較後、アスティルの完全な本文を接尾辞なしの正式URLへ移した。2組とも `-2` は削除せず、`noindex`、正式URLのcanonical、即時移動と手動リンクを持つ案内ページにした。

## 整理するときの順序

1. 新しい重複候補を定期的に検査する。
2. 旧URLを整理するときは `data/url-history.json` に移し、転送ページは残す。
3. 変更のたびに全内部リンクと公開ページを確認する。
4. `docs/STATE.md`、`docs/AI引き継ぎ.md`、ロードマップを更新する。
