# 地図データ更新手順

最終更新：2026-09-07（Codex）

## 正本

- 施設・座標：`data/map-facilities.json`
- 表示ページ：`map/index.html`
- 反映スクリプト：`scripts/build_map_data.py`

`map/index.html` の施設配列は生成物です。施設や座標を直接書き換えません。

## 座標を追加する手順

1. 施設の公式ページなどで、施設名・都道府県・市区町村・住所が同じことを確認する。
2. `data/map-facilities.json` の該当施設へ緯度 `lat` と経度 `lng` を追加する。
3. 次を順番に実行する。

```powershell
python scripts/build_map_data.py
python scripts/build_map_data.py --check
python ..\check-site-links.py
```

4. 地図を開き、ピンが正しい都道府県内にあり、施設名をクリックできることを確認する。
5. `docs/STATE.md` と `docs/AI引き継ぎ.md` に、追加件数と確認方法を書く。
