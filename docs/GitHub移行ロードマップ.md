# GOMIRACHELIN GitHub移行ロードマップ

最終更新：2026-09-05

## 目的

ConoHaへの日常的な更新を止め、GitHubを唯一の編集元にする。検証用サイトで問題がないことを確認してから `sauna-cospa.com` の公開先を切り替え、ConoHaは契約期限まで復旧用として残す。

## 基本方針

- 新しいページ・修正・作業記録はGitHubだけに保存する。
- 現在のConoHaサイトは更新せず、移行完了まで旧サイトとして稼働させる。
- GAS地図とGoogle Sheetsは当面継続する。
- ConoHaを解約する前に、ファイルとWordPressデータベースの最終バックアップを保存する。
- GitHub PagesのテストURLで確認が終わるまで、独自ドメインの向き先を変更しない。

## フェーズ0：準備済み

期間：2026-09-05まで

- GitHubに静的サイトの主要ファイルを保存。
- GAS地図をバージョン91へ更新。
- GitHubトップのメニューへ「サウナ地図」を追加。
- `AGENTS.md`、`CLAUDE.md`、`GEMINI.md` と共通ルールを整備。
- `docs/STATE.md` と `docs/AI引き継ぎ.md` を整備。

完了条件：GitHubを作業の正本として使える。

## フェーズ1：ConoHaの棚卸しとバックアップ

目安：1週間

- ConoHaの公開フォルダーを一度だけ丸ごとバックアップする。
- WordPressデータベースと `wp-content/uploads` をバックアップする。
- DNS、独自ドメイン、メールのMX・TXT設定を記録する。
- 公開サイトの全URLを一覧化し、GitHubにあるURLと比較する。
- 画像、PDF、アイコン、`robots.txt`、リダイレクト設定の不足を一覧化する。

完了条件：復旧可能なバックアップと「GitHubに不足しているもの一覧」がある。

## フェーズ2：GitHubの不足を補完・整理

目安：2週間

- 不足しているページと画像だけをGitHubへ追加する。
- 既知の不足ファイル `sauna-app.webmanifest` と `sauna-icon-180.png` を確認する。
- フォルダーを整理する前に、全URLとリンク先の対応表を作る。
- 公開中のGASソースを、秘密情報を含めず `gas/` に保存する。
- 不要ファイルはすぐ削除せず、候補一覧を作ってから小分けに整理する。

完了条件：公開に必要なページと素材がGitHubにそろい、既知の不足が0件になる。

## フェーズ3：GitHub Pagesのテスト公開

目安：2週間

- 非公開リポジトリのまま有料プランを使うか、安全確認後に公開リポジトリへ変更するか決める。
- GitHub Pagesを一時URLで公開する。
- 必要なら `.nojekyll` と公開フォルダーを設定する。
- パソコンとスマートフォンでトップ、ランキング、レビュー、サウナ大学、地図を確認する。
- 日本語URL、CSS、画像、内部リンク、外部リンク、問い合わせ導線を確認する。
- 404、ブラウザーエラー、HTTP画像の混在を確認する。

完了条件：重大な表示崩れとリンク切れが0件で、主要な利用動線を最後まで操作できる。

## フェーズ4：独自ドメイン切替の準備

目安：1週間

- `sauna-cospa.com` の管理会社と現在のDNS設定を確認する。
- GitHub Pagesで独自ドメインを検証する。
- Webサイト用のA・CNAMEだけを変更する計画を作り、メール用MX・TXTを維持する。
- 切替前のDNS値と、ConoHaへ戻す手順を保存する。
- HTTPSが有効になるまでの確認手順を決める。

完了条件：切替と元に戻す手順が文書化され、メール設定を壊さないことを確認できる。

## フェーズ5：`sauna-cospa.com` を切替・監視

目安：1か月

- 独自ドメインをGitHub Pagesへ向ける。
- HTTPS、主要ページ、GAS地図、アクセス解析を確認する。
- 404と表示崩れを確認し、GitHub側だけを修正する。
- 検索エンジン向けの `sitemap.xml` と `robots.txt` を確認する。
- ConoHaは変更せず、復旧用として残す。

完了条件：30日間、重大な問題がなく、ConoHaへ戻す必要がない。

## フェーズ6：ConoHaを終了

目安：契約期限の1か月前

- ConoHaにしかないファイル、データベース、メールがないことを再確認する。
- 最終バックアップを2か所に保存する。
- ドメイン管理とメールがConoHa解約の影響を受けないことを確認する。
- WordPressとConoHaを解約する。
- `docs/STATE.md` に解約日と最終バックアップ先を記録する。

完了条件：`sauna-cospa.com` がGitHub側で安定稼働し、ConoHaへの依存が0件になる。

## 現在の次の作業

## 中止条件

- バックアップが作成できない場合は、削除・移動・DNS変更をしない。
- メールの管理先が不明な場合は、DNSを変更しない。
- テスト公開に重大な404や表示崩れがある場合は、独自ドメインを切り替えない。
